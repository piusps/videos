Feedback on the first autonomous run (Website, 2026-09-24):
- Gestures: NOT fewer — realistic VARIETY (open arms, close, small explain, occasional point, rest), never the same motion repeated; variety builds viewer trust. Reference nikvideo2final is the benchmark.
- Zooms: wide base, ~3 hard keyframed push-ins (one ~186%), smooth ease in/out — not a new level every sentence.
- B-Roll: always animated throughout, one consistent style across videos: clean Apple UI, glass style, Superkind orange accent. No static 5s stills.
- B-Roll must never look like stock footage (rooms, desks, people) — always animated techy software/startup UI, ideally Remotion-built like WebsiteScrollBroll.
- Avatar head/face was too stiff: motion prompt must demand head nods/tilts/turns/eyebrows that follow the gestures.
- Never start a new HeyGen render for feedback-only requests; user posts the video themselves and only wants the skill updated.
- Don't repeat the trigger word after the CTA sentence.
- Voice sounded less real than reference — cause not yet isolated.
- Silence-cut "Stimme an Stimme" was good — keep. New keyframed zooms (v2) were liked; keep quality loss minimal, avoid paid HeyGen upscales.
- Retention learnings (proof-hook, announced step count, felt payoff, result shown early, no tool jargon, re-hook every ~7s, scroller simulation) live in the video-script skill (Step 3, retention architecture).

**Why:** user reviews as a TikTok scroller; realism and visual variety drive retention.
**How to apply:** baked into the phase skills (video-script, video-avatar-render, video-broll, video-post-production); check them before every render. See [[feedback-autonomous-video-runs]].
