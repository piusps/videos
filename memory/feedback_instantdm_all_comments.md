Every InstantDM post automation (Lead Gen) uses Step 1 = **"All Comments"**, never "Custom Keywords" only. Every post also gets its own **custom comment replies** (Step 2, 4-6 topic-specific variants: short "sent" line + one easy question), never the leftovers from the library template.

**Why:** Pius, 2026-10-07: "immer alle kommentare automatisieren, nicht nur die keywords … und immer custom kommentar antworten für jeden post eintragen" — more DMs/leads and more second comments per reel.

**How to apply:** In video-publish step 2 for FP-N, GPT-N and BX-C: after "Browse Library → Apply", switch to "All Comments", replace all reply chips with new post-specific ones, swap PDF + DM texts, then Publish & Activate. Library templates still carry the old post's replies/texts (seen 2026-10-07 with the Urlaub flow), so always replace them. Related: [[reference-instantdm-mcp]], [[feedback-dm-tone]].
