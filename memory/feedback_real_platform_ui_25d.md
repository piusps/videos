Pius 2026-10-26 on the FP-N Google Maps reel: the flat self-drawn map/cards looked like "billiger 2D Microsoft Edge Look". Wanted: the real Google Maps UI, more premium, "nicht 3D aber 2,5D".

**Why:** a generic flat recreation looks cheap; recognisable real UI + depth reads as high-end.

**How to apply:** when a reel shows a platform, rebuild its real UI faithfully (official logo from public/logos, its font e.g. Google Sans, its colours/Material components), place it in 2.5D (tilted map plane with standing pins, extruded buildings, floating panels with perspective tilt + deep shadows, blurred map backdrop). Reusable kit: broll/src/opus/GMapsKit.tsx. Businesses stay fictional. Related: [[feedback-fullframe-theme-world]], [[feedback-real-logos]]
