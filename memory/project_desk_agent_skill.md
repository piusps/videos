Pius's core points:
- the hinge sits on the seam (the morning shot in v2 fails because of this)
- listen first, then act
- finger and cursor stay in sync
- a story with friction (error → "Fuck" → Superkind helps; lid closes)
- a hook kick at the start (someone walks up, opens the laptop)
- more B-roll types (AI + real trailer cuts, full body)
- zooms only where something happens
