Superkind videos are always Outcome-First (Pius, 2026-10-21, after "Warum Instinct viral geht.md"):
- The finished result is in frame 1, then rewind.
- Superkind speaks up proactively.
- The human says ≤ 6 words ("Ja, mach.").
- Effort is only hinted (counter / one "unterwegs gelöst" line).
- A result lands every 2–3 s; the Enter approval stays visible.
- Feed length ≤ 30 s (two tasks ≤ 35 s). Long process versions only for website/retargeting.
- Since v10 (2026-10-21): stage = Claude-style chat UI rebranded Superkind (ivory, serif agent text, no sidebar/avatars/extra buttons, composer with live dictation, quiet result cards). Starts with the agent's line, no Florent hook sentence. Replaces v9's Teams/macOS-glass look ("overload").
- Quality bar: sleek premium-ad feel, soft film grade on the keyboard footage, no stray key presses after Enter, stills checked at ≥ 0.6 scale.
- The endcard claim stays "jeder mitarbeiter. / sein eigenes team."

**Why:** nobody watches 64 s; the brain wants results, not process. This fits the website positioning: an AI employee you write to in Outlook/Teams/Slack, who asks before anything goes out.
