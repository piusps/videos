Since 2026-10-26 Pius wants his week to-dos in Notion (Notion connector). Database "Wochenplan To-dos": https://app.notion.com/p/9b97288a9988410d83a3dae5d08795b5, data source `collection://6b4bc2fc-e2a9-4913-9a18-cc2e761bcb13`. Properties: Aufgabe (title), Status (Offen/Läuft/Erledigt), Fällig (date), Projekt (Ads, Accounts täglich, pickthecompany, Felix, Privat Niklas & Henri, Review), Zeit (text). Private workspace-level page; the old "Meine Aufgaben" DB on Home has no usable data source.

Pius' format (2026-10-26, after the first 16-task version was "zu viele"): few tasks (~8/week, one per project block, daily routine = ONE task with a date range), property Priorität (Hoch/Mittel/Niedrig), view "Nach Fälligkeit" sorted Fällig ASC then Priorität. Every task page = small onboarding: Ziel, Ablauf/checklist, Hooks/ideas, Tools & Dateien, Was wir verbessern, Fertig wenn.

**How to apply:** add new weekly plans/to-dos here in that format. Daily routine see [[project-daily-routine]].
