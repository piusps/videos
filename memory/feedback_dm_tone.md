All automated Instagram texts (comment replies, DMs, follow gate, lead-gen questions) carry **no emojis** and read like Florent typing personally: short plain sentences, "du", no bot phrases ("Fast geschafft", "Hier ist dein Guide 👇"). Every public comment reply = a short "sent" line plus **one easy question** about the viewer (their experience, either/or, a number, branch, next-topic wish) so they comment again.

**Why:** Pius (2026-10-01): emoji-heavy copy feels "sloppy automatisiert"; people should feel they're chatting with the guy himself, and replies should trigger more comments.

**Confirmed 2026-10-02 (Pius on the AGB reel: "solche custom Kommentar-Antworten sind mega geil"):** 5 replies per video, each tied to the video's topic and the viewer's own situation, e.g. „Hast du auf deiner Seite gerade überhaupt AGB?“, „Verkaufst du eher an Firmen oder an Privatkunden?“, „Hast du deine AGB damals vom Anwalt oder irgendwo kopiert?“. Keep doing this for every video. Never fall back to generic replies.

**How to apply:** use the texts in the video-publish skill §2; write new topic-specific comment questions per video. Related: [[reference-instantdm-mcp]], [[feedback-full-delivery]].
