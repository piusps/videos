Every episode of the 100-Tage series (@florent_preusser, Agents100DayN) must be understandable and valuable for someone who never saw an episode.
- Frame 1 / first sentence = the viewer's problem + promise ("Keiner antwortet auf deine LinkedIn-Nachrichten? So fasst du nach, ohne zu nerven."), with the finished result (e.g. the ready message card) visible from the first frame.
- Then the series frame in ONE plain sentence ("Ich lass hundert Tage lang eine KI mein Unternehmen führen, heute ist Tag N.").
- Story context explained, never assumed ("Vor vier Tagen hat mein Vertrieb 20 Nachrichten verschickt", not "die 20 von Tag 2").
- Insider mechanics (residents, "6 von euch eingezogen", bots) not in the opening; explain them once at the CTA ("…und du ziehst als Bot in meine Firma ein, wie schon 25 andere").

- The value is a concrete cheat code anyone can copy from the screen (e.g. the exact prompt typed live, the exact sentence to send), not abstract rules; show it in frame 1 too.

**Why:** Pius 2026-10-26 rejected Tag 6 v1, which opened with "Über Nacht sind sechs von euch eingezogen": new viewers don't get the value or the story; then v2 still had too little value: "der Mehrwert muss ein richtig krasser Cheatcode sein, mit dem alle was anfangen können".
**How to apply:** check every series script against this order before TTS. Related: [[project-100-agenten-series]], [[feedback-firma-serie-hook]], [[feedback-outcome-first]].
